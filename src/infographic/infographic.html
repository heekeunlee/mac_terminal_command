이동하고 둘러보기

터미널을 열면 가장 먼저 쓰는 다섯 단어

01

pwd

print working directory

지금 내가 있는 폴더 위치를 알려준다

% pwd
/Users/me/Documents

유래결과가 종이에 인쇄되던 텔레타이프 시절의 흔적이라 화면 출력인데도 'print'라고 부른다.

-P실제 경로
02

cd

change directory

다른 폴더로 이동한다

% cd Documents
→ 프롬프트가 ~/Documents 로 바뀜
% cd ..
→ 한 단계 위 폴더로

유래초기 유닉스에서는 chdir였다. 가장 많이 치는 명령이라 두 글자로 줄었다.

~홈 폴더..위 폴더-직전 폴더
03

ls

list

폴더 안에 무엇이 있는지 보여준다

% ls -la
drwxr-xr-x 5 me staff 160 notes
-rw-r--r-- 1 me staff 52 .env

유래점(.)으로 시작하는 '숨김 파일'은 ls가 .과 ..을 감추려던 코드의 부작용에서 생겨난 관례다.

-llong 자세히-aall 숨김까지-h읽기 쉬운 단위
04

cat

concatenate

파일 내용을 화면에 그대로 보여준다

% cat memo.txt
오늘 할 일: 강의 자료 정리

유래고양이와는 무관하다. '사슬처럼 이어 붙이다'라는 뜻으로, 원래 여러 파일을 이어 붙이는 명령이었다.

-n줄 번호a b > c두 파일 합치기
05

man

manual

명령어의 공식 설명서를 연다

% man ls
LS(1) General Commands Manual
→ q 를 누르면 닫힘

유래1971년 첫 유닉스 설명서 형식이 지금까지 그대로 이어진다. 모르는 명령은 man부터.

-k 단어관련 명령 찾기/단어설명서 안 검색
「두 글자로 말하는 사람들」 맥 터미널 명령어 사전에서zsh(%) 기준 · 예시 결과는 이해를 돕기 위한 것

파일과 폴더 다루기

만들고, 복사하고, 옮기고, 지우기

06

mkdir

make directory

새 폴더를 만든다

% mkdir -p 2026/10/notes
→ 중간 폴더까지 한 번에 생성

유래유닉스 명령은 성공하면 아무 말도 하지 않는다. 조용하다면 잘 된 것이다.

-pparents 중간 폴더도
07

touch

touch · 살짝 건드리다

빈 파일을 만든다

% touch index.html
→ 크기 0짜리 새 파일 생성

유래원래는 파일을 '살짝 건드려' 수정 시각만 바꾸는 명령이었다. 새 파일이 생기는 부수 효과가 더 유명해졌다.

a{1..3}.md번호 붙여 여러 개
08

cp

copy

복사본을 만든다. 원본은 그대로

% cp report.txt backup.txt
% cp -R project/ project_bak/
→ 폴더째 복사

유래대상 파일이 이미 있으면 묻지 않고 덮어쓴다. 중요한 파일은 -i를 붙이는 습관을.

-RRecursive 폴더째-iinteractive 묻기-n덮어쓰지 않기
09

mv

move

옮기거나 이름을 바꾼다. 원본은 사라진다

% mv old.txt new.txt
→ 이름만 바뀜
% mv *.pdf ~/Documents/
→ PDF 전부 이동

유래같은 디스크 안에서는 실제로 복사하지 않고 목차만 바꿔서, 수십 GB도 순식간에 '이동'한다.

-i덮어쓰기 전 묻기-n있으면 그대로
10

rm

remove

휴지통 없이 바로 지운다

% rm -i draft.txt
remove draft.txt? y
% rm -r old_project/

유래2015년 한 게임 플랫폼의 스크립트에서 변수 하나가 비면서 rm -rf가 사용자 파일을 통째로 지운 사고가 있었다.

-rrecursive 폴더째-i하나씩 확인-fforce 강제

찾고, 쓰고, 권한 주기

원하는 것을 찾아내고 다루는 법

11

grep

global regular expression print

파일 속에서 글자를 찾아낸다

% grep -rn "TODO" src/
src/App.tsx:42:// TODO: 3장 추가

유래옛 편집기 ed의 명령 g/re/p에서 왔다. 켄 톰슨이 하룻밤 만에 독립 프로그램으로 만들었다는 일화가 있다.

-r하위 폴더까지-i대소문자 무시-n줄 번호
12

find

find · 찾다

조건에 맞는 파일을 찾아낸다

% find ~ -size +1G
/Users/me/Movies/lecture.mov
% find . -name "*.pdf"

유래find는 파일을, grep은 내용을 찾는다. 이 한 문장으로 둘을 구분하면 헷갈리지 않는다.

-name이름으로-type d폴더만-mtime -77일 이내 수정
13

echo

echo · 메아리

입력한 말을 그대로 되돌려준다

% echo $HOME
/Users/me
% echo "한 줄" >> note.txt

유래외친 말을 돌려주는 메아리처럼 글자를 출력한다. 변수 확인과 파일 쓰기에 매일 쓰인다.

>덮어쓰기>>덧붙이기
14

chmod

change mode

누가 읽고 쓰고 실행할지 정한다

% chmod +x run.sh
→ 실행할 수 있게 됨
% chmod 755 run.sh

유래읽기 r=4, 쓰기 w=2, 실행 x=1은 2진수 자리값이다. 더하면 권한 숫자가 된다. 4+2+1=7.

+x실행 권한 추가755나 전부, 남 읽기·실행-R폴더 전체
15

sudo

superuser do

이 명령 하나만 관리자 권한으로 실행한다

% sudo !!
Password:
→ 입력해도 안 보이는 게 정상

유래1980년 미국 뉴욕주립대 버펄로에서 탄생. 웹툰 xkcd의 'sudo 샌드위치 만들어 줘' 농담으로 유명하다.

!!직전 명령을 관리자로-k다음엔 다시 묻기

실행 중인 것을 다루고, 밖과 연결하기

16

ps

process status

지금 실행 중인 프로그램을 보여준다

% ps aux | grep node
me 4821 98.2 node server.js

유래두 번째 칸의 숫자(PID)가 프로그램의 고유 번호다. 멈출 때 이 번호가 필요하다.

aux모든 프로그램 자세히-rCPU 많이 쓰는 순
17

kill

kill · 신호를 보내다

프로그램에 신호를 보내 멈추게 한다

% kill 4821
→ 정리하고 끝내 달라는 요청
% kill -9 4821
→ 거부할 수 없는 강제 종료

유래이름은 '죽이다'지만 실제로는 신호를 보내는 명령이다. -9만 프로그램이 거부할 수 없다.

-9강제 종료killall 앱이름으로 종료
18

curl

client URL

인터넷 주소와 데이터를 주고받는다

% curl -O https://example.com/a.zip
% curl wttr.in/Seoul
→ 터미널에 서울 날씨가 그림으로

유래1996년 스웨덴의 다니엘 스텐베리가 만든 httpget이 urlget을 거쳐 curl이 되었다.

-O원래 이름으로 저장-L옮긴 주소 따라가기-I응답 정보만
19

ssh

secure shell

다른 컴퓨터에 안전하게 접속한다

% ssh me@myserver.com
me@myserver:~$
→ 서버를 내 맥처럼 조작

유래1995년 핀란드의 타투 윌로넨이 대학 네트워크에서 비밀번호를 도둑맞은 뒤 직접 만든 암호화 접속 도구다.

-pport 포트 번호-iidentity 키 파일exit접속 끝내기
20

tar

tape archive

여러 파일을 하나로 묶고 푼다

% tar -czvf backup.tar.gz docs/
→ docs 폴더를 하나로 압축
% tar -xzvf backup.tar.gz

유래1970년대 자기 테이프에 파일을 이어 기록하던 시절의 이름이다. 묶인 파일을 '타볼(tarball)'이라 부른다.
